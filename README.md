A tiny Node program that writes one code review comment of at most 140 characters to `/output/entry.txt`: a flat, tired-engineer approval — "LGTM, ship it" — whose dread comes quietly from the fact that the sun will eventually delete production anyway, on-call included. The program holds the line in one place, checks it against the gate (single line, 1–140 characters, not blank), and writes it deterministically with no trailing newline.

## Run it

```sh
node main.ts
```
